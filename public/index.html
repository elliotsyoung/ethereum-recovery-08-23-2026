Choose your wallet

Everything stays in this local workspace.

Paste the absolute path to your Ethereum V3 JSON keystore.

The demo uses a test wallet with a known password and a small search.

2

The two words

Enter likely words or spelling variations, in order of likelihood.

Separate words with spaces, commas, or new lines. English letters A–Z only, up to 200 distinct words per list. Leave the second list blank to try every pairing from the first list, including both orders.

3

Numbers & symbols

Use ranges if your memory is approximate.

Digits and symbols both count toward the combined nonletter total. The defaults try two digits plus two to four symbols: four to six combined. Adjust these ranges to try a different split.

Only US keyboard Shift symbols, including ! @ # $ % ^ & * ( ) _ + { } | : " < > ? ~. Remove symbols you can rule out.

Refine capitalization & placement
Word capitalization

Selected capitalization styles apply to both words together. “As entered” keeps each word’s own capitalization.

Where the numbers and symbols go

Each selected layout is searched. Repeated digits apply within each group, so split groups can differ. All combinations can make the search much larger.
