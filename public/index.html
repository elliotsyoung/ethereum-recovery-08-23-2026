What can you rule out?

Answer from memory, not from example passwords. “Unknown” keeps the wider search.

If length is uncertain, keep 11–64, the supported range. A tighter range excludes every password outside it.

Work through your memory before choosing filters
  1. Length: do you remember a minimum, maximum, or several possible lengths? Use the entire plausible range.
  2. Characters: what exact characters, misspellings, abbreviations, or keyboard sequences might have appeared? Keep alternatives.
  3. Position: is a remembered piece definitely at the beginning, end, or a known position? If not, do not fix it there.
  4. Case: could capitals be mixed, inside a fragment, or different between fragments? Do not infer Title case.
  5. Numbers: could there be zero digits, leading zeroes, repeated digits, or more than one run? Do you know values or just a count?
  6. Punctuation: could symbols be unshifted, different from each other, or between letters? Include every plausible symbol.
  7. Structure: are two fragments and their order certain? Concatenated fragments cover only that hypothesis.

Notes stay in this tab and are not saved or sent to the search. Only the controls below change coverage.

Keep unknown characters open

No word list, dictionary, or rhyme rule is required.

Type only characters and positions you know. Literal letters preserve their exact case. Multiple lines include every listed alternative. Patterns are also limited by the length range above.

?x
Any allowed character
?a
Any English letter
?l / ?u
Lowercase / uppercase letter
?d / ?s
Digit / punctuation or space
??
Literal question mark
?x{3,8}
3–8 unknown characters

For example, an exact remembered prefix followed by unknown characters can be entered as Prefix?x{5,58}. Use that shape only if the prefix and its position are certain. Blank patterns include uppercase, lowercase, digits, and all 32 ASCII punctuation characters and space, in any order. Non-English letters are outside this search.

A targeted hypothesis has limited coverage. This mode tries two supplied letter fragments, chosen capitalization styles, digits, and trailing symbols. It does not cover every character arrangement. Use the pattern mode for mixed case, symbols within fragments, or other arrangements.
3

Which letter fragments are possible?

Include misspellings and invented strings. No dictionary check is applied.

Separate entries with spaces, commas, or new lines. A–Z and a–z, 1–32 letters, up to 200 distinct entries per list. Blank second list tries all pairings, including both orders and identical fragments. A separate second list fixes the order of the two lists.

Leave each range at 1–32 unless you can exclude other fragment lengths.

4

What do you know about digits and symbols?

Keep ranges wide when a count or value is uncertain.

Counts of zero remain possible by default. This fragment mode supports at most 12 digits and 12 symbols. Use pattern mode for larger counts.

A value bound applies separately to every contiguous run of digits. Leading zeroes are included.

All 32 ASCII punctuation characters and space are allowed, including unshifted characters such as hyphen, equals, brackets, slash, and apostrophe. Removing a character excludes it entirely.

Which capitalization styles remain possible?

Each style applies to both fragments together. “Exactly as entered” preserves the capitalization of each entry. These choices do not cover every mixed-case variation.

Which placements remain possible?

Each selected layout is included. Symbols are a trailing group in all three layouts. Use pattern mode if another position is possible.
